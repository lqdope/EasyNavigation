# EasyNavigation

[![License: CC BY-NC 4.0](https://img.shields.io/badge/License-CC%20BY--NC%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc/4.0/)

**EasyNavigation** — это легковесное и интуитивно понятное решение для реализации навигации в помещении.

## 📋 Описание
Этот проект создан для того, чтобы упростить процесс навигции внутри здания.

## ✨ Особенности
- Простота интеграции.
- Минимальное количество зависимостей.
- Простая настройка.
